# handbook/ — project-authored docs

- `runbooks/` — how to do things: local-dev, deploy, testing, migrations, aws-identities, line-bot (parked).
- `product/vision.md` — the product vision and the 2026-09 website-first pivot.
- `research/` — frozen research; `00-product-principles.md` §4 is the live heuristic register (`research/README.md`).
- `design/` — the decided direction, mockups (the visual bar), token candidates, moodboard (`design/README.md`).
- `archive/` — history only, never current (`archive/README.md`).

Status lives in the root `STATUS.md`, decisions in `DECISIONS.md`. The sibling `docs/` is the cached
vendor documentation, not project docs.
